# Worked example 2 — 180 MBH, 40 ft run, 3.0 in. w.c. drop system

At the 40 ft column of the 3.0 in. w.c. table: 1/2" = 214 CFH, already above
the 180 CFH load → **1/2"** is enough on this higher-drop basis. The same load
on the 0.5 in. w.c. table at 40 ft would need 1" (320 CFH; 3/4" gives only 170).

Command: `python3 gas_pipe.py 180 40 30`
